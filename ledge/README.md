# Ledge at Golden Hour

An interactive Three.js illustration: a masked hero and a stray cat on a brick rooftop ledge above a golden-hour city, rendered to look like an inked comic panel.

## Features
- Cel shading with a custom post-process pass for ink outlines (depth + normal edge detection), near-field cross-hatching and paper grain
- Procedural city: textured facades, water towers, rooftop clutter, harbor and distant shore
- Time-of-day slider (morning, golden hour, dusk, night) with moving sun, shadows, sky, fog and lit windows
- Mouse parallax, drag to look, scroll or pinch to zoom
- Tap the hero (he turns and waves), the cat, or the sky (pigeons scatter)

## Run
Open `index.html` in a browser, or serve the folder with any static server. No build step. Three.js r128 loads from cdnjs.
